# Punch Mine: App Name Options

Alternative App Store names for each language, in case the current one is taken. Every name is 30 characters or fewer (the App Store limit).

- Only the **primary language** name (English U.K.) must be unique when you create the app; the others are checked when each language is saved.
- If even "Punch Mine" alone is taken, every option here will be rejected. Change the brand slightly instead (for example **Punch Mine!**, **PunchMine** or **Punch Mine Idle**).
- If the chosen name contains a word that's also in that language's keywords (such as "Clicker" or "Tycoon"), remove it from the keywords. Words in the name already count for search.
