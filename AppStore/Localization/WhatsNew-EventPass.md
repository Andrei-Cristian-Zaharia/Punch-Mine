## Event Pass setup (same for every language)

- **Product ID:** `punchmine.eventpass`
- **Type:** Consumable
- **Reference name:** Event Pass
- **Price:** $4.99
- **Review screenshot:** the event screen showing the Event Pass card
- **Review notes:** One product reused for every seasonal event. It unlocks the premium reward track of the event running when it is bought, and can't be bought again during that same event. If no event is running, the purchase pays 3 Golden Chests instead.
